# CSE 110 Volleyball Roster Application

Java coursework completed for CSE 110 at Arizona State University.

The application manages a volleyball roster through a menu-driven console interface. It can load player data from a file, list players, add players, update player statistics, count roster members, and identify top attackers and blockers.

## Concepts used

- Java classes and objects
- Constructors, getters, and setters
- `ArrayList`
- File input with `FileInputStream` and `Scanner`
- Menu-driven console input
- Searching and updating object data
- Iteration and simple ranking logic

## Source files

- `Main.java` — program flow and menu interaction
- `Roster.java` — roster storage, file loading, search, and ranking operations
- `Player.java` — player data model

This repository copy is presented as coursework evidence and reflects the source files used for the assignment.
